# Support

- **Questions and ideas**: ask in [GitHub Discussions](https://github.com/nomofly/open-miniprogram-runtime/discussions).
- **Bugs or differences from WeChat's behavior**: open an issue with the [issue templates](https://github.com/nomofly/open-miniprogram-runtime/issues/new/choose) and include a minimal reproduction.
- **Security vulnerabilities**: report them privately as described in [SECURITY.md](./SECURITY.md).

This project is maintained by volunteers, so response times are not guaranteed. A clear description and a minimal reproduction make issues much faster to resolve.

This project is not affiliated with Tencent or the WeChat team. For problems with WeChat DevTools or the WeChat app itself, use the [WeChat Open Community](https://developers.weixin.qq.com/community/develop).
